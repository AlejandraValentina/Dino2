# Evidencia Etapa 15

Esta carpeta conserva referencias de verificación para el primer bloque implementado (perfiles de alzada 4T). Los resultados sintéticos no son mediciones ni validación experimental.

- `../stage14c/README.md`: reproducción de la base numérica preservada.
- `cam-profile-synthetic.csv`: fixture reproducible, explícitamente sintético.
- `verification.log`: suite completa posterior a la implementación.
- `reserved-seeds.log`: semillas 14C reservadas reproducidas.
- `portable.sha256`: portable extraído, hashes de assemblies y comprobación de runtime.
- `../../docs/etapa15.md`: modelo, ecuaciones, estado de los diferidos y decisión científica.
- `manifest.sha256`: manifiesto de fuentes, pruebas, documentos y binario entregado.
- `../../artifacts/stage15/Dino2-stage15-win-x64.zip`: paquete autocontenido Windows x64.

El perfil se verifica con puntos analíticos, una importación CSV sintética, periodicidad de 720° y una simulación de motor sintética marcada como tal. No se incluye un archivo de leva presentado como dato medido.
